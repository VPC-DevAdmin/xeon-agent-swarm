Replay and serving reference

CPU utilization uses the busier hardware thread on each physical core. The CPU work bar uses recorded process-family samples, normalized to attributed CPU work. Memory shows the host sample in GB.

The selected interval keeps all five agent types resident. Lane counts follow recorded arrivals and completions, including agents already resident when the interval begins. Unfinished agents remain resident until the recording ends. The loop returns directly to its recorded steady-state start without replaying startup or drain-down.

The highlighted workflow explains the agent definition. The recording contains aggregate stage timings, not every worker transition or model-call timestamp. The illustration does not report those events as telemetry.
