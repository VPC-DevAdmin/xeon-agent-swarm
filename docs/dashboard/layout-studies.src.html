Enterprise agent capacity

Enterprise agents do five kinds of work, and most of it runs on the CPU.

A support ticket is a few model calls. A data analysis is three sandbox jobs over a hundred million rows. The mix decides what the servers do all day.

One Xeon 6 CPU carries 143 working agents at this mix.

Measured, not modeled: a 25-minute steady state on one 64-core socket, three seeds, every workflow finishing at its reference latency.

Where the CPU time goes

Sandbox jobs dominate. Retrieval and embedding are small once they run as CPU services instead of model calls.
